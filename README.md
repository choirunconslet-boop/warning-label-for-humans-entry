Entry for the make.fun bounty **"Warning Label for Humans"**
(`u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85`).

`main.py` writes one single-line safety warning label for human beings to
`/output/entry.txt`:

> WARNING: This human is 90% water, 10% coffee, and 100% convinced everyone else is the problem.

Pure Python stdlib, no network, no reads outside the repo.
